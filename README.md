# Calculadora de economia

Protótipo inicial de interface para simular economia com energia solar compartilhada. Este repositório registra uma etapa de aprendizado; não é apresentado como produto comercial concluído.

## Executar

O arquivo HTML tem o nome `index.html.html`. Com Python instalado, execute na raiz:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Abra `http://127.0.0.1:8000/index.html.html`. Não há build ou backend.

## Limitações

Tarifas e outros parâmetros estão definidos no JavaScript. Não há consulta automática de preços, garantia de economia ou suíte automatizada de testes. Antes de reaproveitar qualquer cálculo, valide fórmulas, entradas inválidas e premissas com os responsáveis pelo negócio.

Para outra versão do simulador, consulte [ibiapaba-solar](https://github.com/iamnothuman7/ibiapaba-solar).
